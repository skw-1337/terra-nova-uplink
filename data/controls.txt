# Every key of Terra Nova Uplink in one list, read by the launcher's Controls page and by the in-game menu's
# (scripts/controls.gd, launcher/TerraNovaUplink.cs ControlsModel). One line a command:
#   group | id | name | default key | where it is kept
# group: Move, Fight, View, Squad, Map, Drone, System (the game's commands, as Terra Nova Plus changes them: TNPlus.ini
# key_game_<id> and mouse_<id>), Tools (Terra Nova Plus's own keys: key_<id>), Uplink (Uplink's own keys: the
# launcher's key_<id>). The key: a PC scancode in hex (80 + the code for a key of the grey block, as TN+ writes them;
# E0xx for Uplink's), after SHIFT+, CTRL+ or ALT+; - : none; MID, M4, M5: a mouse button (Uplink's order wheel).
# "fixed": the game's own, which cannot be changed. Centre view comes without a key (F is the freelook's).
