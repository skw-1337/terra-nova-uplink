# Every key of Terra Nova Uplink in one list, read by the launcher's Controls page and by the in-game menu's
# (scripts/controls.gd, launcher/TerraNovaUplink.cs ControlsModel). One line a command:
#   group | id | name | default key | where it is kept
# group: Move, Fight, View, Squad, Map, Drone, System (the game's commands, as Terra Nova Plus changes them: TNPlus.ini
# key_game_<id> and mouse_<id>), Tools (Terra Nova Plus's own keys: key_<id>), Uplink (Uplink's own keys: the
# launcher's key_<id>). The key: a PC scancode in hex (80 + the code for a key of the grey block, as TN+ writes them;
# E0xx for Uplink's), after SHIFT+, CTRL+ or ALT+; - : none; MID, M4, M5: a mouse button (Uplink's order wheel).
# "fixed": the game's own, which cannot be changed. (mapout / mapin: TN+'s names for the game's 33 and 34, which zoom
# the map in and out: the names shown are what the keys do in the game.) Centre view comes without a key (F is the freelook's).
# The old school look on \ (2B: free in the game; it was on F12, the game's Mission info): an installation made before
# keeps F12 (the launcher's keys_gen 1), shown as a clash.
# A sixth column: the co-op guest's gamepad (scripts/pad_map.gd; his window only: the host's and a solo game's
# pad is the game's own DOS joystick through DOSBox): B<n> a button, A<n>+ / A<n>- an axis past its threshold
# (Godot's numbers: B0 A, B1 B, B2 X, B3 Y, B4 Back, B6 Start, B7 / B8 the sticks pressed, B9 LB, B10 RB, B11-B14 the
# D-pad up, down, left, right; A0 / A1 left stick, A2 / A3 right stick, A4 LT, A5 RT). Kind "pad": a gamepad's
# own command, no key (the sticks move and look; see the Sticks settings).
